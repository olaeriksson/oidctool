# Project Rules & Guidelines

- **English Only**: Source code, variable names, functions, documentation, commits, and UI must be 100% in English.
- **Open Source Ready**: Ensure clean architecture, no secrets/credentials committed, and standard open-source conventions.
- **Continuous Documentation**: Keep `README.md` in the project root updated continuously with installation, configuration, packaging, and usage notes.
- **Desktop Application**: Built with Electron for Linux and Windows.
- **Packaging Maintenance**: Maintain cross-platform packaging configurations (AppImage, deb for Linux; NSIS, portable for Windows) at all times. Update build configuration whenever the app evolves.
- **Technology Stack**: JavaScript / Node.js.
